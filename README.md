# لوحة الدفع العائلية

منصة لإدارة الدخل والمصاريف والاشتراكات الشهرية بالليرة التركية والدولار، مع سعر صرف تاريخي محفوظ لكل شهر. تعمل على الكمبيوتر كخادم محلي، ومعها تطبيق للآيفون يعمل دون إنترنت ويتزامن مع الكمبيوتر.

> هذا المستودع فيه الكود فقط. البيانات (قاعدة البيانات وملفات Excel) تبقى على أجهزتك ولا تُرفع.

## التشغيل على الكمبيوتر

انقر نقرًا مزدوجًا على `start.bat`. تفتح المنصة في المتصفح على http://localhost:4600

أو من الطرفية:

```bash
npm install
npm start
```

يتطلب Node.js 22.13 أو أحدث.

## أين تُحفظ البيانات

- قاعدة البيانات: `data/finance.db` (SQLite)
- نسخ احتياطية يومية تلقائية (آخر 30): `data/backups/`
- التصدير إلى Excel أو JSON من: الإعدادات ← البيانات

## سعر الصرف

- المصدر: أسعار البنك المركزي الأوروبي عبر Frankfurter، واحتياطيًا currency-api.
- لكل شهر سعره (متوسط أيام العمل افتراضيًا)، يتحدث حتى نهاية الشهر ثم يُقفل.
- البند الذي له «تاريخ عملية» يأخذ سعر ذلك اليوم ويُحفظ عليه.
- دون اتصال: يُحفظ البند بعملته وتظهر عليه علامة «السعر معلّق»، ويُجلب سعر يومه الحقيقي عند أول اتصال.

## الاستيراد من Excel

الإعدادات ← البيانات والاستيراد. يتعرف تلقائيًا على جداول الأشهر والعمليات اليومية، ويعرض معاينة (جديد، مكرر، تعارض) قبل الاعتماد، ويمكن التراجع عن الاستيراد كاملًا. إذا كُتب داخل عمود اسم بند آخر يُقرأ العمود كذلك البند من ذلك الشهر فصاعدًا.

## التكرار والإدخال السريع

- أي بند في صفحة الشهر يمكن تحويله لبند متكرر بفترات ومبالغ متغيرة.
- الإضافة السريعة تقترح أوصافك السابقة وفئتها، وتبويب «عدة عمليات» يقبل سطرًا لكل عملية مثل `خبز 60`.

## تطبيق الآيفون (يعمل دون إنترنت)

تطبيق ويب يُثبَّت على الشاشة الرئيسية (PWA)، منشور على GitHub Pages. يحمل نسخة كاملة من البيانات داخل الهاتف (SQLite)، ويشغّل نفس كود المنصة، فيعمل في أي مكان دون إنترنت.

**التثبيت:** افتح رابط التطبيق في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية»، ثم افتحه من أيقونته.

**نقل البيانات (كملف، دون اتصال مباشر ولا VPN):**

- من الكمبيوتر إلى الهاتف: المنصة ← الإعدادات ← تطبيق الهاتف ← «تصدير نسخة للهاتف»، ثم في التطبيق: الإعدادات ← البيانات ← «استعادة من ملف».
- من الهاتف إلى الكمبيوتر: في التطبيق «نسخة احتياطية الآن»، ثم في المنصة «استيراد نسخة من الهاتف».
- كل نقل يستبدل النسخة كاملة بعد عرض مقارنة بين النسختين، والمنصة تأخذ نسخة احتياطية تلقائية قبل الاستبدال. الإدخال اليومي على الهاتف، والكمبيوتر للنسخ الاحتياطي واستيراد Excel.

**التنبيهات:** زر 🔔 في رأس كل صفحة، ونافذة تلقائية عند فتح التطبيق بالالتزامات المتأخرة والمستحقة اليوم وغدًا (الاسم والمبلغ والموعد) مع زر «دُفع». المواعيد تُستنتج من تاريخ البند أو يوم الاستحقاق المحفوظ للبند المعتاد أو المتكرر، ويمكن تحديد اليوم للبنود التي بلا موعد من النافذة نفسها.

**النسخ الاحتياطي:** حذف أيقونة التطبيق يحذف بياناته من الهاتف، لذلك يذكّر التطبيق بأخذ نسخة إذا مرّ أسبوع دونها.

**التحديثات:** كل تحديث على الفرع `main` يُنشر تلقائيًا (GitHub Actions)، ويظهر في التطبيق شريط «تحديث جديد جاهز».

## للمطوّر

| المسار | الدور |
| --- | --- |
| `server/schema.js` | بنية قاعدة البيانات وترقياتها (مشتركة بين الكمبيوتر والهاتف) |
| `server/core.js`, `server/routes.js` | منطق المنصة ومسارات الواجهة (مشتركة) |
| `server/index.js` | خادم الكمبيوتر (Express) |
| `server/transfer.js` | نقل البيانات مع الهاتف كملف: تصدير، فحص ومقارنة، استبدال |
| `server/router.js` | موجّه داخلي يشغّل مسارات `routes.js` داخل الهاتف |
| `server/sqlwrap.js` | غلاف موحّد لقاعدة البيانات (node:sqlite وSQLite WASM) |
| `public/js/alerts.js` | مركز التنبيهات |
| `public/` | الواجهة (مشتركة) |
| `pwa/` | تطبيق الهاتف: المحرك، الواجهة الإضافية، عامل الخدمة، البناء |

```bash
npm run build:pwa   # يبني pwa/dist
npm run serve:pwa   # تجربة على http://localhost:4620
```

تصحيحات البيانات الخاصة بجهاز معيّن توضع في `server/local-fixes.js` (مستبعد من المستودع).
